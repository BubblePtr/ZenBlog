# ADR-0001：设计系统从「留白」升级为「书桌」

- 状态：已接受
- 日期：2026-09-12
- 影响文件：`DESIGN.md`、`src/styles/global.css`、`docs/design/colors.md`、首页与项目页组件

## 背景

v2「留白」系统（2026-08）把站点做成一页安静的纸：单一强调色、不引入 display 字体、无阴影无卡片、零入场动效、图片能不用就不用。它解决了 v1 杂志系统的过度装饰，但带来新问题：

- 所有页面都一样平。项目缩略图和文章列表行是同一种存在，作品没有被「展示」。
- 站点主人想表达设计判断，但系统没有留出任何表达位置。
- 项目集合补到四条以后（PR #111），16:10 网格已经是这套规则下能做到的上限。

参考了两类外部样本：手写标注式的产品说明图（箭头加短注），和 Interface Craft 式的扇形卡堆。它们分别对应「讲解」和「展示」两个 v2 没有的动作。

## 决策

保留纸墨底子，引入「书桌」隐喻，把元素分为纸上（文字层）、桌上（实物层）、纸边（旁注层）三层，并只对后两层放开规则。具体放开三条，每条都有边界：

1. **颜色**：青竹继续是唯一 wayfinding 色。新增五个低饱和传统色作为「封面色」，只用于实物（项目卡、系列徽标、标注墨色），以染纸的面出现，不进文字层。
2. **字体**：一款显示衬线（Instrument Serif，中文 Noto Serif SC）进界面层，只担任标题角色；一款手写体（Caveat，中文霞鹜文楷子集）只担任旁注角色，八词以内、四处以内。正文与导航仍是 MiSans。
3. **深度与动效**：实物层允许双层柔影、层叠、倾斜，两级深度。首屏允许一次 120 到 200ms 的轻入场，最多四个元素。scroll 触发、parallax、自动轮播继续禁止。

## 考虑过的替代方案

- **只加手写旁注，其余不动**：改动最小，但项目区依旧平，解决不了「作品没有被展示」。
- **彻底换调色板与主字体**：表达空间最大，但青竹的色彩叙事和 MiSans 的跨平台一致性是站点身份的一部分，换掉等于换站。
- **全面放开动效**：会把站点推向「作品集网站」的表演感，和写作优先的定位冲突。

## 后果

- 需要新增两款自托管字体和一个中文手写字体子集脚本，页面字体载荷会上升，靠子集化和 preload 控制。
- 项目 frontmatter 新增 `cover` 字段；少于三个项目时卡堆退回网格。
- `docs/design/colors.md` 的角色 token 表要补封面色一节；文中青竹彩度以 `global.css` 为准（C 0.075 / 0.08），v2 DESIGN.md 里的 0.046 是过时值，本次一并纠正。
- 已废弃的 v1 杂志元素（kicker、folio、双导轨、三栏页脚）继续禁止，不因本次放开而复活。
