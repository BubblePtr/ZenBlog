# 项目卡堆（Project Deck）：决策记录

- 日期：2026-09-12
- 来源：`/proto/deck` 原型对比（四个变体：Fan、Spread、Ledger、Lift），已删除
- 实施：`src/shared/components/content/ProjectDeck.astro`，用于首页项目区与项目页顶部

## 选定：Lift（扇形 + 点击抬起）

- 静置：四到六张卡扇形层叠，倾斜 ±4° 递增，横向重叠 56px，外侧卡略低。hover 当前卡摆正抬起 8px。
- 点击：该卡 FLIP 到卡堆顶部中线，摆正、放大 1.35 倍，露出描述与"Open project"入口，320ms `cubic-bezier(0.32, 0.72, 0, 1)`。其余卡片下沉 `--retreat`（380px）、向中心收拢（每档 36px）、缩小到 0.85。容器 `padding-bottom` 同步过渡，这是唯一被动画的布局属性。
- 再点：进入项目。点另一张：直接换。Esc 或点空白：收回。
- 卡堆下方一行手写体提示（Caveat，墨弱色），是首页允许的第二处"无所指旁注"。
- 移动端：横向滚动 + scroll-snap，不倾斜不抬起，点一次进项目。`prefers-reduced-motion`：静态网格，无过渡。
- 少于三张卡：退回普通网格。

## 否决

- **Fan（只 hover 摆正）**：首屏效果同 Lift，但没有"看描述"的动作，卡片永远看不全。被 Lift 完全覆盖。
- **Spread（平铺微倾斜）**：不遮挡、最易读，但实物感最弱，本质还是网格；第五张掉行。
- **Ledger（一大图 + 列表切换）**：描述最完整、可扩展，但首屏只露一个封面，站点主人希望作品一眼全露。
- **Lift 第一版（上方预留 460px 空位）**：静置时一大块空白，被否决；改为点击后其余卡片退避让位。

## 记录到的坑

- oxlint 会把 Astro 标记内注释里的 `---` 当成 frontmatter 分隔符，`{/* */}` 注释也会让整文件解析失败。
- 扇形的 `--dy`（下沉偏移）与抬起位移撞名会让收回停在半空；抬起位移用 `--lx/--ly`。
- Tailwind v4 `@theme` 新增变量后需重启 dev server，HMR 不会重建主题变量。
