Make Pi fit you.

Pi's package ecosystem grew past five thousand entries fast, and the official registry tells you what exists but not what is worth installing. Awesome Pi is the community-maintained shortlist: extensions, skills, themes and prompt templates, grouped by what they do, each with a one-line pitch and the install command.

The list lives as a plain README so anyone can send a pull request. The companion site renders the same data with category filters, search, and copy-to-install buttons, in English and Chinese. It is the most-starred repository I maintain and the entry point I hand to people who ask how to set up Pi.
