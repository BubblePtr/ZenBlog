Just speak. We'll handle the rest.

Voily is a voice input method for macOS: press one key, speak, and polished text lands wherever your cursor is. If you can type there, you can speak there — Slack, Cursor, Gmail, ChatGPT, any app that takes text.

Instead of raw dictation, Voily runs your speech through an AI rewrite pipeline, so what lands is refined text rather than a literal transcript. It sits quietly in the menu bar, always ready behind a single hotkey.

The app is open source and built for macOS 14+ on Apple Silicon, with signed and notarized releases shipped through GitHub Releases and auto-updated via Sparkle. I'm building it in public — the journey is documented in the weekly notes on this blog.
